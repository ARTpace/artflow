# 插件平台 V0–V1 实施记录

日期：2026-09-23　｜　范围：审计与生命周期加固　｜　不代表 V2–V8 已完成

## 1. 本批结果

- scoped register/provide/on 自动归属；旧 Kernel 注解的 builtin 继续工作。
- 激活前重复 ID、依赖与兼容校验；作用域暂存、成功发布、失败反向回滚。
- 根贡献、服务、监听 disposer 幂等，旧登记不会误删新登记；取消监听不再收到事件快照的迟到调用。
- `effects.defer`、受管 timer、AbortSignal、可取消/超时的异步激活；可选 `effects.track` + 有界 `disposeAsync`。
- provider 有 required dependent 时拒绝卸载；退出顺序由消费者到 provider。
- `builtin.arrange-tools` 的 4 条命令去掉手写 pluginId 与 disposer 数组，以真实插件验证自动归属。
- 设置管理器仍 staged + reload；没有 UI 热卸载、外部安装器或新的任务队列。

## 4. 最小用法与契约

```ts
activate(ctx: ScopedPluginContext): void {
  ctx.contributions.register('commands', {
    id: 'sample.inspect',
    value: inspectCommand,
  }); // pluginId 与撤销由作用域管理
  ctx.on('sample.changed', handleChange);
  ctx.provide('sample.service', service, () => service.close());
  ctx.effects.defer(() => releaseSynchronousResource());
  ctx.effects.setInterval(refresh, 1000); // commit 后才启动
}
```

- 同步入口继续供现有启动调用；返回的 legacy Effect 也自动收集，旧手动 disposer 不会导致二次删除。
- 需要 await 的激活使用 `loadBuiltinPluginAsync(root, module, { signal, timeoutMs })`，默认 10000ms。同步入口遇 Promise 报错而不是假装已经激活。
- `effects.track(signal => operation(signal))` 只跟踪显式加入的 Promise；不会拦截所有 service/command/fetch 调用。需要延续运行的任务应由既有 jobs/import 所有者管理，不为此另造调度器。
- 同步 dispose 遇到受管在途调用会要求 disposeAsync；后者默认最多等待 5000ms，超时后返回 timedOut:true 并清理作用域。调用方必须检查该结果。
- Effect/资源 cleanup 是同步契约；本批不承诺等待返回 Promise 的任意 cleanup。裸 timer、任意网络/DOM副作用以及持有的原始 service 对象不在自动撤销保证内。
- `requires` 是本批卸载保护依据；插件 provider 消费者应显式声明 required dependency。optionalRequires 不阻止 provider 卸载；没有自动代理/追踪全部服务对象引用。
- 激活失败/超时关闭作用域能阻止迟到注册，不会撤回已发出的外部请求或强行终止 JS 死循环。资源预算声明不等于硬配额。

## 6. 未测与剩余风险

- 未执行 Windows Electron 真机点击、reload、真实用户项目保存/恢复与长时间压力测试；SSR/基础契约通过不能代替这些验收。
- 没有本轮 FPS、内存硬上限或 GPU 测量；不以本批生命周期测试宣称性能提升。
- 外部源码树安装 Sample Asset Inspector、真实 provider 网络生成、worker/process 故障隔离、权限授权、动态节点保存/恢复仍待 V2–V8。
- 当前受管 Promise 取消是合作式，忽略 AbortSignal 的工作可在超时后继续，但不能通过关闭的 scoped context 再注册。
- 所有 UI 插件仍可信同进程；不能把 scoped context 描述成安全沙箱。

建议人工验收：正常启动 → Palette 中排列命令存在且可撤销 → 皮肤/面板/设置可打开 → 对可管理插件 stage 开关，reload 后生效 → 恢复开关 → 打开/保存既有 v2 项目。使用测试项目，勿据此触碰生产资产目录。
