# ADR-031：交互帧预算与按需重型模块边界

- 状态：verified
- 日期：2026-09-22
- 轮次：R31 / Phase Perf1
- 关联：`FDD-031-PhasePerf1交互帧合并与启动按需加载.md`

## 背景

现有 R11–R17 已建立 renderer-local viewport index 与交互候选复用，但真实热路径仍有三类可测开销：

1. 高频鼠标事件会逐事件触发 React / `Board[]` 更新，输入频率可显著高于屏幕刷新率；
2. R11 mutable query 为保持 source order 会扫描完整 `order`，且 sparse update 会重复三次遍历同一 `Element[]`；
3. 启动入口静态导入 Three.js、所有 3D loader、PSD/PDF/TIFF/RAW parser 与全部 builtin card，普通启动也支付重型能力成本。

这些问题不需要改变 storage、IPC、文档 schema 或引入 Hybrid renderer 即可先收敛。

## 决策

### 1. 输入更新服从显示帧预算

`useCanvasInteractions` 只保留最新绝对 pointer sample，并通过 `requestAnimationFrame` 每帧最多执行一次 canvas/React 更新。`mouseup` 必须同步 flush 最后一个 sample；AI rotate、框选与套索通过 transient ref 保留 flush 后的最终语义，不能读取仍在批处理中的旧 React state。

此决策只合并事件，不改变 snapping、resize、draw、erase、selection、parenting 或最终 operation commit 规则。

### 2. live viewport query 与文档规模解耦

R11 mutable grid query 只排序网格返回的 candidate id，不再为 source order 扫描全部 id。`orderById` 是 mount-scoped renderer cache metadata。

flat immutable cache update 将 structure validation 与 changed-reference collection 合并为一次遍历；group、增删、重排、重复 id 等情况继续保守 full rebuild。

### 3. 重型格式与卡片按实际使用加载

- builtin cards 仍在启动期注册相同 contribution，但 component 实现使用 `React.lazy`，只在对应卡片进入可见渲染路径时加载；
- Canvas card host 提供局部 `Suspense` fallback；
- PSD/PDF/audio/image parser 在 handler `parse()` 内动态导入；
- ordinary file import 动态导入 `fileUtils`；PSD、TIFF、RAW decoder 继续二级按格式加载；
- 3D extension detection 拆到无 Three.js 依赖的 `model3dFormats.ts`，文件路由不得静态拉入 renderer/loader 实现。

manifest、handler priority、card node type、persisted data 和 plugin lifecycle 保持不变。

### 4. SVG defs 跟随可见集合

rounded-image clip defs 仅为 `visibleElements` 生成。离屏元素本来不挂载，无需保留对应 DOM defs；重新进入视口时随元素一起恢复。

## 结果

同一远端环境、10k/100 sparse fixture：

- cached sparse update/query：`99.34 ms → 22.67 ms`，降低约 77%；
- sparse speedup：`1.69x → 7.17x`；
- production startup entry：`2788.70 kB → 811.01 kB`，降低约 71%；
- startup entry gzip：`769.61 kB → 214.27 kB`，降低约 72%。

PSD、PDF、UTIF 与 Model3D/Three.js 现在生成独立异步 chunk。数字是本轮同机证据，不是跨设备 FPS 保证。

## 不变量与回退

- R11 cache ownership 仍在 `MainCanvas`；R12/R13 saved query 不进入 live hot path；
- group/structural update 仍 full rebuild；本 ADR 不声明 group incremental propagation；
- pointer sample 合并必须 flush on mouseup，不能牺牲最终位置或最终选择；
- lazy chunk 失败由现有 Error boundary/overlay 后续硬化，本轮不引入远程 CDN 或新执行权限；
- fixed preload/main capability 仍为 13；无 schema、IPC、Node capability 或 npm dependency 变化。

## 明确不做

Hybrid Canvas/WebGL、normalized entity store、Worker live index、tile/LOD renderer、group dependency propagation、Layer Panel virtualization、wheel inertia、parser Worker、import transaction/batch/retry、media resource budget均不在 R31；需要独立 FDD/ADR。
