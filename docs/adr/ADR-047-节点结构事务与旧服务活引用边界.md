# ADR-047：节点结构事务与旧服务活引用边界

日期：2026-09-23。状态：实现与自动/独立浏览器验证通过，Electron 真机待验。检查结论见《插件平台V2收尾实施记录》。延续 ADR-045/046。

## 决策

1. 保留同一个 document state、session/revision 与 operationHistory。新增纯 planner，不另起 reducer/历史/持久化系统。
2. 公共操作增加 node.createText、node.delete、node.reparent；与已有几何 patch 可组成一个原子批次。每个节点每批至多一个操作，所有 schema 与最终拓扑通过后只写一条现有历史。
3. createText 只创建现有内建 text 节点：验证坐标/尺寸/字号/十六进制颜色/文本长度/ID/parent，禁止资产字段、未知属性或任意节点 schema。创建通用媒体节点仍需资产所有权协议，不能凭 locator 绕过库。
4. 删除是显式节点操作，不删除资产文件或释放 undo/redo 所需资源。删除容器不得自动丢弃子孙或静默改父级；调用者必须在同一事务中显式删除/移出相关节点，否则拒绝。
5. 父节点须为存在的 frame/group，最终图不得有环/悬空父引用。拓扑验证迭代进行。锁定节点及其锁定祖先保护不能借 reparent/delete 绕过。普通几何 patch 仍不承担 group 子孙变换。
6. App 仅通用地在删除提交后清理当前画板对应选区；切板后不能误删另一个画板的同名选区。selection 清理异常不反转已经提交的文档事务。
7. legacy export/mutation/view-state 三个服务提供稳定方法 facade，每次调用（包括缓存的方法引用）都查当前 ref；卸载后旧 facade 拒绝调用。保留旧接口与行为，不将这些兼容接口冒充新 SDK 的权限或 revision 保证。
8. 正常 schema 校验先于 requestId 去重，状态相关规划在去重/版本/交互检查之后。重复请求不因节点已被 undo/delete 而重复执行。
9. dedupe 最多 256 项且估算字符串体积 8 MiB，超限淘汰仍依赖 revision 防旧请求覆盖；不是硬进程内存配额。
10. 新操作沿用同步 renderer 合作式生命周期；不是恶意代码隔离。保持固定 IPC、资产/staging 所有权与现有项目文档 v2。

## 范围

本批完成 V2 最小结构操作和旧服务闭包收尾，不宣称完成 V3 导入后台化、V4 动态节点契约、V5 Hook/Agent 最终守卫、V6 外部宿主、V7 第三方 provider 或 V8 端到端验收。真实 Electron UI、磁盘 I/O、大项目性能和外部隔离仍须分别验收。
